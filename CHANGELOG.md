## [0.1.0] - 2026-07-24

### Added

- Agent-oriented SearXNG search with task profiles, live engine validation, pagination, URL deduplication, and partial-failure reporting.
- Public web-page reading with DNS and redirect validation, pinned connections, response limits, and SSRF protection.
- Capability inspection, autocomplete, engine discovery, machine-readable schemas, structured output formats, and a read-only raw API escape hatch.
- Four bundled Agent Skills with safe installation, status, update, and uninstall commands for Codex and Claude.
