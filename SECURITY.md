# Security Policy

## Supported versions

Security fixes are provided for the latest released minor version.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use the repository's **Security → Report a vulnerability** form to submit a private advisory.

Include the affected version, reproduction steps, impact, and any suggested mitigation. You should receive an acknowledgement within seven days. Please allow time for a fix and coordinated disclosure before publishing details.

The `read` command deliberately blocks private, reserved, loopback, and credential-bearing URLs unless the caller explicitly opts into private access. Reports about bypasses of these controls are especially welcome.
